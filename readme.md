# 📘 Gestion des mails et des actions

Ce dépôt présente deux méthodes complémentaires pour organiser les mails et les actions au quotidien :

* 📥 [Gestion des mails](./mails.md) — trier les messages, garder une boîte de réception vide et traiter les actions qu'ils contiennent.
* 📋 [Gestion des actions](./todo.md) — capturer, classer, prioriser et suivre les actions issues des mails, des réunions ou d'autres demandes.

## 🔄 Comment utiliser ces méthodes

Traitez immédiatement les mails dont l'action prend moins de 2 minutes. Pour les actions plus longues, enregistrez-les dans votre liste d'actions, puis classez le mail afin de libérer la boîte de réception. Les deux méthodes sont détaillées dans leurs documents respectifs.
